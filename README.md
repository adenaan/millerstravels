# Miller's Travel & Tours — React + Vite

## Run locally
```bash
npm install
npm run dev
```

## Admin (demo)
- URL: `/admin`
- Username: `admin`
- Password: `demo123`

## Data storage
- Packages: localStorage key `millers:packages`
- Site config: localStorage key `millers:siteConfig`

To reset data, clear your browser localStorage for this site.
